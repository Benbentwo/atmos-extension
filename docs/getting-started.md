# Getting Started

This extension helps navigate Atmos stacks defined in your workspace.

1. Install dependencies:
   ```bash
   pnpm install
   ```
2. Open this folder in VS Code.
3. Press `F5` to launch a new Extension Development Host.
4. Open a project containing an `atmos.yaml` file.
5. Use command-click on `import:` lines to follow stack imports relative to `stacks.base_path`, or see the **Atmos Stacks** view in the Explorer.
